Connect to GitHub

Changes are saved straight into the dashboard's GitHub repository and appear on the live dashboard about a minute later. You need a GitHub access token with write access to this repository only.

How to get a token (one time, 2 minutes)
  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it dashboard-admin and pick an expiry (for example 1 year).
  3. Repository access: Only select repositories → YashInfoTech13/Dashboard.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate, copy the token and paste it above. Don't share it; anyone with it can edit the dashboard.
